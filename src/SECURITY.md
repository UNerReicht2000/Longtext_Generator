# SECURITY.md

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not create a public issue**.  
Instead, report it privately by emailing:

**Contact:** [your-email@example.com]

Please include as much detail as possible to help us address the issue quickly.

---

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.x   | :x:                |

---

## Security Recommendations

- Keep your Python environment and dependencies up to date.
- Only use the application in trusted environments.
- Do not open untrusted files with this tool.

---

## Responsible Disclosure

We aim to respond to vulnerability reports within **5 business days**.  
After confirming the issue, we will work to release a fix as soon as possible and acknowledge your contribution if desired.
